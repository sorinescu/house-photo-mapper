<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User file input → PersistenceService | User selects .hpmpj file; path traversal or malicious JSON possible |
| QSettings → Application | macOS plist stores window state, recent projects; tampered plist could affect behavior |
| File dialog → Application | User selects save location; path validation needed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1-05 | Tampering | PersistenceService.load_project | high | mitigate | pydantic model_validate_json validates schema; reject extra fields; Path.resolve() + is_relative_to() for path safety |
| T-1-06 | Tampering | PersistenceService.save_project_as | medium | mitigate | Validate new_path parent exists and is writable; atomic write prevents partial files |
| T-1-07 | Information Disclosure | QSettings recent projects | low | accept | Recent projects list is user-controlled; no sensitive data |
| T-1-08 | Denial of Service | Malformed .hpmpj file | medium | mitigate | pydantic validation fails fast; error_occurred signal surfaces to UI; app doesn't crash |

</threat_model>
