<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Downloaded DMG → User system | Untrusted artifact installed to /Applications; must be notarized |
| App bundle → macOS Gatekeeper | codesign + notarization proves identity and integrity |
| App → User files (Open/Save) | User-selected files only; sandbox via Hardened Runtime + entitlements |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1-15 | Spoofing | Unsigned/modified .app | critical | mitigate | codesign --options runtime + notarization; spctl assessment |
| T-1-16 | Tampering | Modified DMG in transit | high | mitigate | Notarization staples ticket; HTTPS distribution; SHA256 checksums |
| T-1-17 | Elevation | DYLD injection via unsigned dylibs | high | mitigate | Hardened Runtime + disable-library-validation only where needed |
| T-1-18 | Information Disclosure | Crash logs with paths | low | accept | structlog JSON logs; no PII in crash reports |
| T-1-19 | Denial of Service | Expired certificate | medium | mitigate | CI monitors cert expiry; renew 30 days before |

</threat_model>
