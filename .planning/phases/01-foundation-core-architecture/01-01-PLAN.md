<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Dependency resolution → Project | uv downloads packages from PyPI; malicious package could execute code at install time |
| pre-commit hooks → Developer machine | Hooks execute arbitrary code from .pre-commit-config.yaml repos |
| pyappdist build → macOS bundle | Build process downloads Python runtime; supply chain risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1-01 | Tampering | uv dependency resolution | high | mitigate | uv.lock committed; `uv sync --locked` in CI; no unpinned dependencies |
| T-1-02 | Tampering | pre-commit hook sources | medium | mitigate | Pin hook revisions in .pre-commit-config.yaml; review new hooks before adding |
| T-1-03 | Elevation | pyappdist runtime download | medium | mitigate | pyappdist pins Python version; verify SHA256 in CI build logs |
| T-1-04 | Spoofing | Malicious package on PyPI | high | mitigate | Package Legitimacy Audit in RESEARCH.md verified all packages; only approved packages in pyproject.toml |

</threat_model>
