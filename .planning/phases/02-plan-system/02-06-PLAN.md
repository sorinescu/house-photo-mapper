  <action>
Add `import_plan()` slot to MainWindowViewModel in `main_window_vm.py`:

1. Add a `plan_vm` property that returns the PlanViewModel from ProjectViewModel (expose `self._project_vm._plan_vm`). The ProjectViewModel already stores `_plan_vm` set via `set_plan_vm()`. MainWindowViewModel needs a way to access it. Add a property `plan_vm` that returns `self._project_vm._plan_vm` (may be None).

2. Add `import_plan` signal (Signal(str)) for status messages.

3. Add `@Slot()` method `import_plan()`:
   - Get last opened directory from `self._persistence.get_last_opend_directory()` for initial path
   - Call `QFileDialog.getOpenFileName(None, "Import Plan", directory, "Plans (*.pdf *.png *.jpg *.jpeg);;PDF Files (*.pdf);;Images (*.png *.jpg *.jpeg)")`
   - If path is empty (user cancelled), return early
   - Extract suffix: `Path(path).suffix.lower()`
   - If suffix == ".pdf": call `plan_vm.load_plan_from_pdf(path)` if plan_vm is not None
   - If suffix in (".png", ".jpg", ".jpeg"): call `plan_vm.load_plan_from_image(path)` if plan_vm is not None
   - If plan_vm is None: emit `self.status_message_changed.emit("No plan viewport available")`
   - Wrap in try/except, emit `self.status_message_changed.emit(f"Failed to import plan: {e}")` on error
   - Call `self._persistence.set_last_opened_directory(str(Path(path).parent))` after successful import

4. In `tests/test_plan_import_ui.py`, create test class `TestMainWindowViewModelImportPlan`:
   - Use `pytest.fixture` to create MainWindowViewModel with mock PersistenceService and mock ProjectViewModel
   - Test each behavior case above using `unittest.mock.patch` on `QFileDialog.getOpenFileName`
   - Verify `load_plan_from_pdf` / `load_plan_from_image` called with correct path
   - Verify no load call when dialog is cancelled
   - Verify error signal on exception

Note: ProjectViewModel._plan_vm is set via set_plan_vm(), which is called by the app wiring. For import_plan to work, MainWindowViewModel needs access to the PlanViewModel. The cleanest approach: expose plan_vm as a property on ProjectViewModel (add `@property def plan_vm(self) -> PlanViewModel | None: return self._plan_vm`), then MainWindowViewModel.plan_vm delegates to `self._project_vm.plan_vm`.
