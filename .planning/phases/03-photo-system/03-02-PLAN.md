# Phase 3, Plan 2: Photo Import Pipeline

**Goal:** User can drag-drop photo files onto the app and import them, and can select a folder to import all photos recursively — with proper EXIF orientation correction and HEIC support.

**Depends on:** 03-01 (PhotoModel exists)

---

## Tasks

### Task 1: Create PhotoImporter service

- [ ] Create `src/house_photo_mapper/domain/services/photo_importer.py` with:
  - `SUPPORTED_FORMATS`: set of `.jpg`, `.jpeg`, `.png`, `.heic`, `.heif`, `.tiff`, `.tif`, `.bmp`
  - `scan_folder_recursive(folder: Path) -> Iterator[Path]`: yields image paths, skips hidden dirs
  - `import_single_photo(path: Path, project_dir: Path) -> PhotoModel`: opens with Pillow, applies `ImageOps.exif_transpose()`, extracts dimensions, computes perceptual hash via `imagehash.dhash()`, returns PhotoModel
  - `import_photos(paths: list[Path], project_dir: Path) -> list[PhotoModel]`: batch import, skips duplicates by path
- [ ] Add `__init__.py` export in `domain/services/`

### Task 2: Create drag-drop integration in MainWindow

- [ ] In `src/house_photo_mapper/presentation/views/main_window.py`:
  - Call `self.setAcceptDrops(True)` in `_setup_ui()`
  - Override `dragEnterEvent()` — accept if any URL has supported image extension
  - Override `dropEvent()` — extract paths, call `self._vm.import_photos(paths)`
- [ ] In `MainWindowViewModel`: add `import_photos(paths: list[str])` slot that delegates to ProjectVM

### Task 3: Create folder import menu action

- [ ] In MainWindow File menu, add "Import &Photos..." action with shortcut Ctrl+Shift+P
  - Open `QFileDialog.getExistingDirectory()` for folder selection
  - Call `scan_folder_recursive()` on selected folder
  - Pass results to `self._vm.import_photos(paths)`
- [ ] Wire action to MainWindowViewModel import_photos method
