# Phase 3, Plan 5: Duplicate Detection

**Goal:** Detect duplicate photos via perceptual hashing (dHash), group them by similarity, and flag them for user review in the photo browser.

**Depends on:** 03-01 (PhotoModel, DuplicateGroup), 03-02 (PhotoImporter)

---

## Tasks

### Task 1: Create DuplicateDetector service

- [ ] Create `src/house_photo_mapper/domain/services/duplicate_detector.py` with:
  - `DuplicateDetector(QObject)`:
    - `detect_duplicates(photos: list[PhotoModel], threshold: int = 10) -> list[DuplicateGroup]`: groups photos by perceptual hash Hamming distance
    - Uses `imagehash.dhash()` for hash computation (already computed during import)
    - Compares all pairs using Hamming distance: `hash1 - hash2 <= threshold`
    - Returns list of DuplicateGroup with group_id, photo_paths, representative_index (first photo)
    - `_compute_hash(path: str) -> str`: computes dHash if not already on PhotoModel
  - `threshold` default 10 (96% similar per research)
  - Background detection: use QRunnable if >50 photos to avoid UI freeze

### Task 2: Add duplicate detection to import pipeline

- [ ] Update `PhotoImporter` to call `DuplicateDetector.detect_duplicates()` after batch import
- [ ] Update PhotoModel.is_duplicate and duplicate_group_id fields based on results
- [ ] Emit signal when duplicates found: `duplicates_found(list[DuplicateGroup])`

### Task 3: Create duplicate review UI

- [ ] In photo browser, add visual indicator for duplicate photos (red border or "Duplicate" badge)
- [ ] Add "Review Duplicates" action to View menu that:
  - Shows dialog listing duplicate groups
  - Each group shows thumbnails side by side
  - User can mark photos to keep or remove
  - "Select All Duplicates" / "Keep First Only" quick actions
