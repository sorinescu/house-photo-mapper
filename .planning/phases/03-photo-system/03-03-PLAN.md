# Phase 3, Plan 3: EXIF Extraction Service

**Goal:** Extract EXIF metadata (timestamp, GPS, camera, lens, orientation) from imported photos and populate the PhotoModel's exif field with correctly formatted data.

**Depends on:** 03-01 (ExifModel exists), 03-02 (PhotoImporter exists)

---

## Tasks

### Task 1: Create ExifExtractor service

- [ ] Create `src/house_photo_mapper/domain/services/exif_extractor.py` with:
  - `extract_exif(path: Path) -> ExifModel`: opens image with Pillow, extracts:
    - `DateTimeOriginal` (tag 306 or 36867) → timestamp string
    - `Make` (tag 271) → camera_make
    - `Model` (tag 272) → camera_model
    - `LensModel` (tag 34665 sub IFD) → lens_model
    - `Orientation` (tag 274) → orientation int (default 1)
    - GPS IFD → gps_lat, gps_lon via `_gps_to_decimal()` helper
  - `_gps_to_decimal(gps_coord, gps_ref) -> float`: converts EXIF rational GPS to decimal degrees
  - Handle missing EXIF gracefully (return ExifModel with defaults)
- [ ] Update `PhotoImporter.import_single_photo()` to call `extract_exif()` and populate exif field

### Task 2: Add unit tests for EXIF extraction

- [ ] Create `tests/test_exif_extractor.py` with:
  - Test with sample JPEG containing known EXIF (create minimal fixture)
  - Test with no EXIF data (returns defaults)
  - Test GPS coordinate conversion from rationals to decimal
  - Test orientation field extraction

### Task 3: Wire EXIF metadata to photo display

- [ ] In PhotoModel, add `display_metadata()` property returning dict for UI display
- [ ] Add status bar message on import showing photo count and EXIF summary
