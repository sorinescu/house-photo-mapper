# Phase 3, Plan 6: PhotoBrowserVM & UI Integration

**Goal:** Complete photo browser with virtual scrolling, metadata display, duplicate badges, and full integration with MainWindow — user can browse photos, see EXIF data, and identify duplicates.

**Depends on:** 03-01 (PhotoModel), 03-02 (PhotoImporter), 03-03 (ExifExtractor), 03-04 (ThumbnailGenerator), 03-05 (DuplicateDetector)

## Tasks

### Task 1: Create PhotoViewModel

- [ ] Create `src/house_photo_mapper/presentation/viewmodels/photo_vm.py` with:
  - `PhotoViewModel(QtSafeViewModel)`:
    - `photos: list[PhotoModel]` — current photo collection
    - `thumbnails: dict[str, QPixmap]` — loaded thumbnails
    - `selected_photo: PhotoModel | None` — currently selected photo
    - Signals: `photo_added(PhotoModel)`, `photo_removed(str)`, `thumbnail_ready(str, QPixmap)`, `duplicates_found(list)`, `selection_changed(PhotoModel)`, `metadata_changed(dict)`
    - `@Slot(list) import_photos(paths: list[str])`: delegates to PhotoImporter, emits signals
    - `@Slot(str) select_photo(path: str)`: sets selected, emits metadata
    - `@Slot() remove_selected()`: removes selected photo
    - `@Slot() review_duplicates()`: opens duplicate review dialog
    - Integrates ThumbnailGenerator: generates thumbnails for new photos, caches results

### Task 2: Create PhotoBrowser widget

- [ ] Create `src/house_photo_mapper/presentation/views/photo_browser.py` with:
  - `PhotoBrowser(QListWidget)`:
    - IconMode with 200x200 icon size, adjustable grid
    - `add_photo(path, thumbnail=None)`: adds item with placeholder or thumbnail
    - `update_thumbnail(path, pixmap)`: updates item icon when thumbnail ready
    - `mark_duplicate(path, group_id)`: adds red border overlay or badge
    - Connects to PhotoViewModel signals for auto-update
    - Lazy loading: only generates thumbnails for visible items (scroll-based)

### Task 3: Create PhotoMetadataPanel widget

- [ ] Create `src/house_photo_mapper/presentation/views/photo_metadata.py` with:
  - `PhotoMetadataPanel(QWidget)`:
    - Shows: filename, dimensions, file size, timestamp, camera, lens, GPS coordinates
    - Form layout with labels and read-only fields
    - Updates when PhotoViewModel.selection_changed emits
    - "No photo selected" placeholder state

### Task 4: Integrate into MainWindow

- [ ] In `MainWindow._create_central_widget()`:
  - Add PhotoBrowser and PhotoMetadataPanel to right side of splitter
  - Splitter: PlanSidebar | PlanView | PhotoBrowser + MetadataPanel
  - Connect PhotoViewModel signals to PhotoBrowser and PhotoMetadataPanel
- [ ] Wire PhotoViewModel to MainWindowViewModel:
  - Add `photo_vm` property to ProjectViewModel
  - Connect import_photos action to PhotoViewModel
