# Phase 3, Plan 4: Thumbnail System

**Goal:** Generate thumbnails in background threads without blocking UI, with LRU memory cache and disk cache for fast reload of 1000+ photos.

**Depends on:** 03-01 (PhotoModel), 03-02 (PhotoImporter)

---

## Tasks

### Task 1: Create ThumbnailGenerator service

- [ ] Create `src/house_photo_mapper/domain/services/thumbnail_generator.py` with:
  - `ThumbnailWorker(QRunnable)`: generates single thumbnail in background thread
    - Opens image with Pillow, applies `ImageOps.exif_transpose()`
    - Resizes to target size (default 200x200) using `Image.Resampling.LANCZOS`
    - Converts to QPixmap via QImage buffer
    - Emits `thumbnail_ready(path, QPixmap)` signal via worker Signals object
    - Uses `QtSafeRunnable` base from `infrastructure/qt_patterns.py`
  - `ThumbnailGenerator(QObject)`: manages background generation
    - `generate(path: str) -> None`: queues thumbnail generation
    - `thumbnail_ready = Signal(str, QPixmap)`: emitted when thumbnail available
    - `_cache: dict[str, QPixmap]`: in-memory LRU cache (max 100MB estimated)
    - `_disk_cache_dir: Path`: `.cache/thumbnails/` in project directory
    - Checks disk cache before generating; saves to disk cache after generation
    - Uses `QThreadPool.globalInstance()` for worker execution

### Task 2: Create thumbnail disk cache

- [ ] Implement disk cache in ThumbnailGenerator:
  - Cache key: MD5 of file path (avoid filesystem sanitization issues)
  - Cache format: PNG files in `.cache/thumbnails/` subdirectory
  - `load_from_disk(path) -> QPixmap | None`: checks disk cache
  - `save_to_disk(path, pixmap) -> None`: saves to disk cache
  - Cache invalidation: skip if source file mtime > cache file mtime

### Task 3: Add memory cache with size limit

- [ ] Implement LRU memory cache in ThumbnailGenerator:
  - `_cache_order: list[str]`: tracks access order for LRU eviction
  - `_max_cache_bytes: int = 100_000_000` (100MB default)
  - `_current_cache_bytes: int`: tracks total pixmap memory
  - `evict_oldest() -> None`: removes oldest cached pixmap when over limit
  - `get_cached(path) -> QPixmap | None`: returns cached thumbnail or None
