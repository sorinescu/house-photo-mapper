Key integration points:
- MainWindow._create_menu_bar() adds File menu actions (line 219-329)
- MainWindow._create_toolbar() adds toolbar actions (line 457-488)
- MainWindowViewModel handles file dialogs and delegates to ProjectViewModel
- AnnotationViewModel.get_all_annotations() returns list of AnnotationModel
- PhotoViewModel.photos returns list of PhotoModel
- ProjectModel.export_settings has page_format, orientation, margin_* fields
- PlanModel.get_sorted_pages() returns list of PageModel with calibration

The _generate_report flow:
1. User clicks File > Generate Report (or toolbar button)
2. MainWindow calls _generate_report()
3. _generate_report creates ReportViewModel
4. Shows LayoutDialog to get page format
5. Builds list of ReportPageData from annotations + photos + plans
6. Calls ReportViewModel.generate_report(pages_data, output_path, page_size)
7. Shows ReportProgressDialog connected to ReportViewModel signals
8. On finished: opens PDF in default viewer, shows status message
9. On error: shows error in status bar
</context>
