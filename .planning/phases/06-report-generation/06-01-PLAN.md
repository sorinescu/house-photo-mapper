    2. extract_plan_snippet() function:
       - Signature: (pdf_path: str, page_index: int, center_x: float, center_y: float, radius_meters: float, pixels_per_meter: float, target_width_px: int = 400, target_height_px: int = 300) -> bytes
       - Opens PDF with fitz.open(pdf_path)
       - Converts scene coordinates to PDF points: pdf_center_x = (center_x / pixels_per_meter) * 72, pdf_center_y = (center_y / pixels_per_meter) * 72

       - Clamps to page bounds: clip = clip & page.rect
       - Accounts for page rotation: if page.rotation != 0, use page.rect for bounds (PyMuPDF handles rotation internally)
       - Calculates zoom to fit target dimensions: zoom = min(target_width_px / clip.width, target_height_px / clip.height)
       - Renders: mat = fitz.Matrix(zoom, zoom); pix = page.get_pixmap(matrix=mat, clip=clip, alpha=False)
       - Returns pix.tobytes("png")
       - Closes document and calls fitz.TOOLS.store_shrink(100) in finally block
