<objective>
Create the core ReportGeneratorService that composes PDF pages, the ReportViewModel for background generation with progress, and the LayoutDialog for user page format selection.

Purpose: This plan delivers the main PDF generation engine and the user-facing components for triggering and monitoring report generation. The service handles per-page composition (photo + plan snippet + overlay + metadata) while the ViewModel manages background execution.

Output: ReportGeneratorService, ReportViewModel, LayoutDialog, and their test files.
</objective>

<context>
Plan 01 created PlanSnippet and CameraOverlay services. This plan builds on those to create the full report generation pipeline.

Key models from existing codebase:
- ExportSettings: page_format ("A4"), orientation ("portrait"), margin_top/bottom/left/right (mm), report_title/subtitle/author, figure_numbering, figure_prefix
- AnnotationModel: annotation_id, photo_path, page_index, position_x, y, direction_angle, cone_angle, title, description, color
- PhotoModel: path, exif (ExifModel with timestamp, camera_make, camera_model, lens_model)
- PageModel: source_path, page_index, rotation, calibration (pixels_per_meter)

ReportLab coordinate system: (0,0) is bottom-left, Y increases upward. Use height - y for top-down thinking.

Page layout (from RESEARCH.md Pattern 1):
- Top 55%: Photo with preserveAspectRatio=True, anchor='nw'
- Middle: Figure number + title
- Bottom: Plan snippet
- Footer: Metadata (camera, lens, date)
</context>

       - __init__(self, project_dir: str)
       - generate(self, pages_data: list[ReportPageData], output_path: str, page_size: str = "A4 Portrait") -> str

         - Figure number + title: "Figure N: {title}" with Helvetica-Bold 12pt
         - Plan snippet: calls extract_plan_snippet(), creates ImageReader from bytes, draws with drawImage
         - Camera overlay: calls draw_camera_overlay() on canvas
         - Metadata: "Camera | Lens | Date" with Helvetica 8pt
       - _build_metadata_string(self, metadata: dict) -> str
         - Formats metadata dict to "Camera Make Model | Lens | YYYY-MM-DD HH:MM" string
