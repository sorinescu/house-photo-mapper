# Plan 04-02: Annotation ViewModel

## Goal
Create AnnotationViewModel to manage annotation creation flow, floor selection, and metadata form.

## Tasks

### 1. Create AnnotationViewModel
- [ ] Create `presentation/viewmodels/annotation_vm.py`
- [ ] Extend `QtSafeViewModel`
- [ ] Manage list of annotations for current page
- [ ] Tool state machine: Select, PlaceMarker, DrawPolygon
- [ ] Signals: annotation_added, annotation_removed, annotation_selected, tool_changed

### 2. Implement Creation Flow
- [ ] Step 1: Place camera marker on plan
- [ ] Step 2: Set direction by dragging from marker
- [ ] Step 3: Adjust cone angle
- [ ] Step 4: Draw visible area polygon (4+ points)
- [ ] Step 5: Enter metadata (title, description, tags)
- [ ] Step 6: Assign floor (default to page floor)

### 3. Implement Floor Selection
- [ ] Default to current page's floor
- [ ] Allow override per annotation
- [ ] Emit floor_changed signal

### 4. Implement Metadata Form
- [ ] Title field (required)
- [ ] Description field (optional)
- [ ] Tags field (comma-separated)
- [ ] Validate required fields before saving

### 5. Integrate with PlanViewModel
- [ ] Add reference to AnnotationViewModel in PlanViewModel
- [ ] Emit annotation-related signals
- [ ] Handle page changes to show/hide annotations

## Verification
- [ ] AnnotationViewModel can be created and connected
- [ ] Tool state machine transitions correctly
- [ ] Creation flow guides user through all steps
- [ ] Floor selection works with default and override
- [ ] Metadata form validates and saves
