# Plan 04-05: Photo-Annotation Binding

## Goal
Bind photos to annotations and implement selection sync between photo browser and plan.

## Tasks

### 1. Add Annotation Binding to PhotoModel
- [ ] Add `annotation_id: Optional[str]` field to PhotoModel
- [ ] Update serialization methods

### 2. Implement Photo Selection Sync
- [ ] When photo is selected in browser, highlight associated annotation on plan
- [ ] When annotation is selected on plan, highlight associated photo in browser
- [ ] Emit selection_changed signals

### 3. Implement Annotation Placement Workflow
- [ ] User selects photo in browser
- [ ] User clicks on plan to place annotation
- [ ] Annotation is created with photo binding
- [ ] Photo is marked as annotated

### 4. Implement Annotation Removal Workflow
- [ ] User selects annotation on plan
- [ ] User presses Delete
- [ ] Annotation is removed
- [ ] Photo binding is cleared

### 5. Implement Annotation Navigation
- [ ] Left/Right arrow keys navigate between annotated photos
- [ ] Show annotation on plan when photo is selected
- [ ] Scroll plan view to show annotation

### 6. Update Persistence
- [ ] Add `save_annotation_model()` to PersistenceService
- [ ] Add `load_annotation_model()` to PersistenceService
- [ ] Save/load annotations.json
- [ ] Update ProjectViewModel save/load to include annotations

## Verification
- [ ] Photo selection highlights annotation on plan
- [ ] Annotation selection highlights photo in browser
- [ ] Annotation placement creates photo binding
- [ ] Annotation removal clears photo binding
- [ ] Arrow keys navigate annotated photos
- [ ] Annotations persist across save/load
