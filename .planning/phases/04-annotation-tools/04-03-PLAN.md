Create `src/house_photo_mapper/presentation/commands/undo_commands.py` with all QUndoCommand subclasses per D-ED-01 through D-ED-04.

1. Define CommandIds enum with unique positive integers for each command type: MOVE_MARKER=1001, ROTATE_ARROW=1002, RESIZE_CONE=1003, EDIT_POLYGON=1004, EDIT_METADATA=1005, DELETE_ANNOTATION=1006, ADD_ANNOTATION=1007.

2. Implement MoveMarkerCommand(QUndoCommand):
   - Constructor takes annotation_id, old_pos, new_pos, vm reference
   - id() returns CommandIds.MOVE_MARKER
   - redo() calls vm._apply_position(annotation_id, new_pos)
   - undo() calls vm._apply_position(annotation_id, old_pos)
   - mergeWith() checks same type and annotation_id, adopts new_pos, returns True
   - setText("Move camera marker")

3. Implement RotateArrowCommand(QUndoCommand):
   - Similar to MoveMarker but for direction angle
   - id() returns CommandIds.ROTATE_ARROW
   - mergeWith() for continuous rotation compression
   - setText("Rotate direction arrow")

4. Implement ResizeConeCommand(QUndoCommand):
   - For cone angle adjustments
   - id() returns CommandIds.RESIZE_CONE
   - Non-mergeable (discrete angle changes)
   - setText("Resize viewing cone")

5. Implement EditPolygonCommand(QUndoCommand):
   - For visible area polygon point changes
   - id() returns CommandIds.EDIT_POLYGON
   - Non-mergeable (polygon edits are discrete)
   - setText("Edit visible area polygon")

6. Implement EditMetadataCommand(QUndoCommand):
   - For title, description, tags changes
   - id() returns CommandIds.EDIT_METADATA
   - Non-mergeable
   - setText("Edit annotation metadata")

7. Implement DeleteAnnotationCommand(QUndoCommand):
   - Stores full annotation data for undo restore
   - id() returns CommandIds.DELETE_ANNOTATION
   - redo() calls vm._remove_annotation(annotation_id)
   - undo() calls vm._restore_annotation(annotation_id, data)
   - setText("Delete annotation")

8. Implement AddAnnotationCommand(QUndoCommand):
   - For adding new annotations via undo stack
   - id() returns CommandIds.ADD_ANNOTATION
   - redo() calls vm._add_annotation_from_data(data)
   - undo() calls vm._remove_annotation(annotation_id)
   - setText("Add annotation")

9. Create test file `tests/unit/test_undo_commands.py` with:
   - TestCommandIds: verify all IDs are unique positive integers
   - TestMoveMarkerCommand: redo/undo cycle, mergeWith behavior
   - TestRotateArrowCommand: redo/undo cycle, mergeWith behavior
   - TestEditPolygonCommand: redo/undo cycle
   - TestEditMetadataCommand: redo/undo cycle
   - TestDeleteAnnotationCommand: redo/undo with data restoration
   - TestAddAnnotationCommand: redo/undo with annotation removal
   - TestMergeCompression: verify drag operations merge into single undo step

10. Add internal methods to AnnotationViewModel for command integration:
    - _apply_position(annotation_id, pos) - set marker position
    - _apply_direction(annotation_id, angle) - set direction angle
    - _apply_visible_area(annotation_id, points) - set polygon points
    - _apply_metadata(annotation_id, meta_dict) - set metadata
    - _remove_annotation(annotation_id) - remove from list
    - _restore_annotation(annotation_id, data) - restore from dict
    - _add_annotation_from_data(data) - add from dict

Per D-ED-01 through D-ED-04: All annotation edits must be undoable with unlimited undo/redo. Continuous drag operations must merge into single undo steps.
