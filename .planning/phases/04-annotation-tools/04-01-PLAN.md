# Plan 04-01: Annotation Graphics Items

## Goal
Create QGraphicsItem subclasses for camera marker, direction arrow, viewing cone, and visible area polygon.

## Tasks

### 1. Create AnnotationModel
- [ ] Create `domain/models/annotation.py` with Pydantic BaseModel
- [ ] Fields: annotation_id (UUID), photo_path, page_index, floor, position_x, position_y, direction_angle, cone_angle, visible_area (list of points), title, description, tags
- [ ] Add `to_project_json()` and `from_project_json()` methods
- [ ] Update `domain/models/__init__.py` to export AnnotationModel

### 2. Create CameraMarkerItem
- [ ] Create `presentation/graphics/annotation_items.py`
- [ ] Implement `CameraMarkerItem(QGraphicsEllipseItem)`
- [ ] Add flags: ItemIsMovable, ItemIsSelectable, ItemSendsGeometryChanges
- [ ] Emit `positionChanged` signal when moved
- [ ] Visual: red circle with camera icon

### 3. Create DirectionArrowItem
- [ ] Implement `DirectionArrowItem(QGraphicsLineItem)`
- [ ] Rotate around camera marker position
- [ ] Emit `angleChanged` signal when rotated
- [ ] Visual: arrow pointing in direction

### 4. Create ViewingConeItem
- [ ] Implement `ViewingConeItem(QGraphicsPolygonItem)`
- [ ] Calculate polygon based on cone angle and direction
- [ ] Update when marker moves or cone angle changes
- [ ] Visual: semi-transparent cone

### 5. Create VisibleAreaItem
- [ ] Implement `VisibleAreaItem(QGraphicsPolygonItem)`
- [ ] Handle 4+ points drawn by user
- [ ] Handle vertex dragging for editing
- [ ] Visual: semi-transparent polygon

### 6. Create AnnotationGraphicsGroup
- [ ] Implement `AnnotationGraphicsGroup` to group all items
- [ ] Single selection/drag unit
- [ ] Z-ordering: polygon (1), cone (2), arrow (3), marker (4)

## Verification
- [ ] All graphics items can be added to QGraphicsScene
- [ ] Camera marker is movable and selectable
- [ ] Direction arrow rotates around marker
- [ ] Viewing cone updates with marker movement
- [ ] Visible area polygon handles vertex editing
- [ ] All items group together for selection
